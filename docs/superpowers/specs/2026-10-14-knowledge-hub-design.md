# DevOps Knowledge Hub

## Outcome and constraints
Vietnamese personal engineering blog and structured learning library as described in the user's attached brief. Complete foundation and core blog before learning areas. Preserve all existing staged deletions. Never commit, upload, move, copy or serve `gôm nhặt trên mạng`; exclude it from Git, type checking and output tracing. No Git push, deployment or invented personal identity.

## Architecture
Next.js App Router, strict TypeScript, Tailwind 4 and owned shadcn components. Default Server Components. Read only allowlisted `content/` Markdown collections with Zod metadata validation; reject duplicate slugs and invalid content with filename-specific errors. Drafts never enter public routes, search or sitemap. Markdown, rather than executable MDX, is sufficient for this MVP. GFM, heading anchors and Shiki run on server; Mermaid is dynamically loaded on demand.

## Experience
Slate/cyan palette, Geist fonts, dark and light tokens, asymmetrical terminal hero. All principal URLs in brief have working routes. Blog supports text/category/tag filters, sorting and pagination. Articles have progress, active TOC, copy code/URL, related and previous/next links. Build-time bounded search snippets cover all collections with command navigation. Interviews filter and expand answers. Certifications have sourced overviews and original quizzes with exact-set grading, review, retry and validated local progress. Three cheatsheets and two roadmaps.

## Verification
Unit checks for metadata, drafts, search, exact-set grading and malformed persisted state. Lint, typecheck, content validation, production build and browser checks for navigation, filtering, theme, search, copy, quizzes and responsive layouts. Check Git ignore/index/history and output tracing for private materials. Content is authored independently with primary-source links.
